# Negocio Gemini

Proyecto desarrollado con Node.js para integrar funcionalidades basadas en la API de Gemini.

## Descripción

Esta aplicación permite ejecutar una integración con Gemini desde un servidor o script de Node.js. La configuración sensible, como la clave de API, se almacena en variables de entorno.

## Tecnologías utilizadas

- Node.js
- JavaScript
- npm
- API de Gemini
- dotenv

## Estructura del proyecto

```text
├── .env                # Variables de entorno privadas
├── app.js              # Archivo principal de la aplicación
├── package.json        # Dependencias y scripts del proyecto
├── package-lock.json   # Versiones exactas de dependencias
└── README.md           # Documentación del proyecto
